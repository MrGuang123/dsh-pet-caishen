# 任务、提醒与设置契约

日期：2026-10-23。对应实施步骤 S0；已接入当前工作树，尚未发布。接口见 [PROTOCOL.md](PROTOCOL.md)，实际验证见 [VALIDATION.md](VALIDATION.md)。

## 三类数据

| 类别 | 所有者与内容 | 生命周期 |
| --- | --- | --- |
| 事实 | 宿主：存活 root 的标题、状态、等待存在标志、真实开始／结束元数据 | 仅内存；root 卸载或插件停用时移除 |
| 提醒 | 宿主生成完成身份，记录是否已确认及已呈现；网页按事件身份执行提示／庆祝 | 仅内存；不能写入偏好或诊断 |
| 表现 | 网页：摸头、求签、睡觉、动作节奏、临时气泡 | 不改变任务事实；重要业务状态和入口始终保留 |

不接收消息正文、工具参数、推理、审批说明或问题正文。所有任务文字使用 `textContent`，角色备用 SVG 是应用自有常量。

## 轮次与事件身份

每个 root 实例创建独立 `sourceId`，真实 `turn/start` 创建新的 `turn.id`；每个真实 completed 创建独立 `completion.id`。均使用本地 UUID，不复用会话 ID。改名、轮询和 waiting 切换不创建新轮次；同轮重复 end 保留第一次结束。宿主仅在内存保存已呈现的提醒标记，页面恢复后不重播旧庆祝；用户仍可主动查询。

启动时发现正在运行但没有观察到开始事件，可创建观察轮次，`startedAt:null`。只有真实开始事件才能填入开始时间。独立 `agent/error` 不造出 turn/end 或结束时间。未知结束原因归为 `unknown`，不显示完成。

结束可能早于 driver 停止：仍保持 waiting > blocked > ready > running > idle 的产品规则，其中 ready 要等 driver 停止且存在未确认 completed；局部表现不参与此排序。

同源内存记录用递增 `revision` 过滤乱序，跨会话同优先级用内存接收序号排序；`updatedAt` 是展示时间，墙钟回拨不能让新事实被旧事实覆盖。卸载后重建相同会话，sourceId 也必须不同。已确认只消除本轮完成提醒，结束事实仍可保留；明确错误与待处理交互不因导航消失。

## 等待与时长

`waiting` 只有 `approval`、`question`、`unknown` 三个存在标志。问题 observer 与问题投影可能指向同一事项，不相加计数；任务面板统计 root 数量。客户端 pending 只能贡献 unknown，8 秒失联后只撤销自己的补正，不清除宿主事实或改变宿主连接状态。

时长仅由真实 `startedAt` 与结束时间／当前时间计算；起点未知不显示数字，时间回拨时显示值下限为零。不计算预计完成时间或百分比。

## 导航确认

气泡生成时捕获 `{sessionId,completionId?}`。新任务抢占优先级不能改变该入口。目标消失、同会话已进入新完成事件时返回 409 并提示重新选择。

导航在唤回 DSH 的异步操作之前入队，并固定 `expectedCompletionId`。确认须匹配导航命令 ID、会话、时效；adapter 还要求完成身份匹配。旧确认不能清除新一轮提醒。

裸 `client-focus` 继续只记录上次聊天。客户端只有在可见、聚焦且已从宿主观察到当前完成身份时，才带 `observedCompletionId` 消退该条提醒；选中会话不表示完整阅读或任务正确。显式收起只操作指定完成身份，不批准或回答任何请求。

## 偏好版本与迁移

持久化 schemaVersion 为 2；HTTP 状态为 v2，Native 握手为 4，三者各自表示不同契约。

| 字段 | 默认／限制 |
| --- | --- |
| size | 160，120–240，整数化 |
| notificationMode | all／attention／quiet，默认 all |
| snoozedUntil | null 或非负安全整数的 epoch 毫秒 |
| reducedMotion、hidden | false；hidden 保留为兼容字段，原生可见性仍以真实上报为准 |
| mini、largeText | false |
| positionLocked、dockEdge | false |
| shortcutKey | 大写 A–Z 或 null（禁用）；修饰键固定 Control+Option+Command，默认 A |
| onboardingSeen | false |

旧文件的 quiet:true 映射 quiet，false 映射 all，保留尺寸、动效和隐藏偏好；合法显式 notificationMode 优先于 quiet。状态仍投影 quiet 布尔别名，存储不重复保存别名。未知字段、版本及非法值拒绝，不能写入标题、会话标识或任意参数。文件损坏时采用明确默认值；磁盘保存失败不发布新状态。

暂静不改变所选模式，只保存绝对截止时间；到期恢复该模式。重启使用原截止时间，不重新计算 30 分钟。系统时间前调可提前到期，回调会按绝对时间增加剩余时长，界面据实显示；不声称使用单调时钟。暂静期间记录事实并抑制自动气泡，到期不补弹积压提醒。

系统与手动减少动态任一开启即采用低动效，覆盖金币及界面过渡；安静陪伴不屏蔽用户主动查询。

## 基线与验收案例

`scripts/baseline.mjs` 复制独立 bundle 并更换偏好域，仅使用虚构任务；采样自身与原生后代进程，不读取进程参数或日常任务。输出在忽略的 output/。ps 的 CPU 值是衰减估计、RSS 可能含共享页，WebKit XPC 不在子树时无法归因；GPU／功耗／帧时间／唤醒次数未测量就保持 null。实际拖动性能需单列，不能用几何单测替代。

自动案例覆盖：并发身份隔离、同会话连续两轮、重复结束、未知起点、先结束后 driver 停止、改名、旧确认晚到、补正过期、偏好迁移、暂静重启与时钟变化。真实库隔离验证、浏览器、原生以及完整安装的结果分别记录。
