# 阿财 0.2.0-rc.2

DSH `0.2.1-rc.5` 兼容修复预发布版。修复升级后插件页显示「异常」、阿财 bundle 被宿主整体跳过的问题；2D 体验与原生程序功能保持 `0.2.0-rc.1`。整体阶段仍有实机验收待办，本版不标记为稳定版；3D 继续后置。

适配 DSH **0.2.1-rc.5**、**macOS 13+**。内置 Apple Silicon／Intel 通用伴随程序，无需 Xcode、构建脚本或首次启动下载；Windows／Linux 暂不支持。

- `engines.dsh` 从精确 `0.2.1-rc.2` 改为 `>=0.2.1-rc.5 <0.2.2-0`，恢复 rc.5 下的插件加载。
- 按 rc.5 安装版源码复核 Host 服务、事件、客户端注入与插槽；状态投影、桥接协议和本地数据格式不变。
- 任务气泡固定到对应会话和本轮提醒；仅真实 completed 显示本轮结束，同一轮只庆祝一次。
- 当前任务列表、提醒分级、暂静 30 分钟、迷你／大字、位置锁定与重置、渲染恢复和最小诊断保持可用。
- 原生握手仍为 4、HTTP 状态仍为 v2；原生程序按 `0.2.0-rc.2` 重新构建，无需迁移既有偏好。

在 DSH「插件」→「添加插件」填入：

```text
git+https://github.com/MrGuang123/dsh-pet-caishen.git#v0.2.0-rc.2
```

也可下载本页的 `dsh-pet-caishen-0.2.0-rc.2.tgz`，在添加插件时填入下载文件的绝对路径；`SHA256SUMS` 提供该包的 SHA-256。升级后必须完全退出并重新打开 DSH，让被跳过的 bundle 重新参与组合；仅刷新页面不会重载宿主插件树。

本插件只使用任务标题、状态及必要交互标志，不读取消息正文、推理或工具参数，不发送遥测。本轮结束不代表测试或工作结果已验证。主题与宠物可以分别启用；财神主题 `0.2.2` 已单独适配 rc.5。

已完成自动回归、干净打包、兼容组合与隔离宿主加载验证，详情见 [验证记录](https://github.com/MrGuang123/dsh-pet-caishen/blob/v0.2.0-rc.2/docs/VALIDATION.md)。完整 DSH 界面流程、真实任务端到端导航、Intel 实机、多屏／全屏 Space、连续拖动／穿透／快捷键、VoiceOver 和睡眠唤醒等专项仍待验收。跨 profile 使用时需配置不同 instanceId 或独立 stateDirectory。预编译程序为 ad-hoc 签名，未做 Developer ID 公证。
