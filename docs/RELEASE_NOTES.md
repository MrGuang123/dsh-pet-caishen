# 阿财 0.2.0-rc.1

2D 体验增强预发布版，包含任务提醒、多任务视图、桌面控制，以及本次气泡滚动条与底部「∨」修复。整体阶段仍有实机验收待办，本版不标记为稳定版；3D 继续后置。

适配 DSH **0.2.1-rc.2**、**macOS 13+**。内置 Apple Silicon／Intel 通用伴随程序，无需 Xcode、构建脚本或首次启动下载；Windows／Linux 暂不支持。

- 任务气泡固定到对应会话和本轮提醒；仅真实 completed 显示本轮结束，同一轮只庆祝一次。
- 增加当前任务列表、数量、可确认的等待类型和运行时长；收起提醒不改变真实结果。
- 增加提醒分级、暂静 30 分钟、迷你／大字、轻互动与统一低动效。
- 增加位置锁定、靠边停靠、位置重置、可选唤回字母、渲染恢复与最小诊断。
- 移除气泡底部看似向下箭头的尖角，统一圆角；短消息不出现多余滚动条，长消息按需滚动，新消息从顶部显示。
- 页面重新加载后重新投递屏幕边界，避免靠边面板失去可见区域约束。

在 DSH「插件」→「添加插件」填入：

```text
git+https://github.com/MrGuang123/dsh-pet-caishen.git#v0.2.0-rc.1
```

也可下载本页的 `dsh-pet-caishen-0.2.0-rc.1.tgz`，在添加插件时填入下载文件的绝对路径；`SHA256SUMS` 提供该包的 SHA-256。更新旧版后按提示刷新或完全退出再打开 DSH；本版 HTTP 状态为 v2、原生协议为 4，需要成套更新。既有外观设置会迁移，原有安静偏好会保留。

本插件只使用任务标题、状态及必要交互标志，不读取消息正文、推理或工具参数，不发送遥测。本轮结束不代表测试或工作结果已验证。主题与宠物可以分别启用，本版未修改财神主题。

已完成自动回归、干净打包与分层隔离验证，详情见 [验证记录](https://github.com/MrGuang123/dsh-pet-caishen/blob/v0.2.0-rc.1/docs/VALIDATION.md)。完整 DSH 界面流程、真实任务端到端导航、Intel 实机、多屏／全屏 Space、连续拖动／穿透／快捷键、VoiceOver 和睡眠唤醒等专项仍待验收。跨 profile 使用时需配置不同 instanceId 或独立 stateDirectory。预编译程序为 ad-hoc 签名，未做 Developer ID 公证。
