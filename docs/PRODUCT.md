# 阿财产品共识

状态：2026-10-19 用户确认的首版范围；开发与验收以本文为准。

## 角色

中文名：阿财；拼音／技术标识：`acai`；英文显示名：**Acai**。

阿财是一位陪伴开发工作的 Q 版小财神。圆脸、短胡子、红衣描金、祥云，与 `theme-caishen` 的暖纸／深檀配色相配；墨镜、咖啡、算盘、元宝是动作道具。性格亲切、幽默，有一点财迷和偷懒，不催促用户加班。

主题继续负责界面外观，阿财负责跨应用陪伴与任务反馈。宠物可独立使用，不要求安装财神主题，不修改主题文件或用户的提示词库。

## 首版核心体验

1. 阿财使用独立透明置顶桌面窗口；切换应用、最小化 DSH 后仍可见。优先 macOS，Windows／Linux 后续单独适配。
2. 可拖动、记住位置、调整大小、收起／唤回；透明空白区域穿透鼠标，不抢正在使用应用的焦点。
3. DSH 运行任务时拨算盘；需要用户决定时举牌；任务结束时抱元宝庆祝；遇到明确错误时挠头；空闲会呼吸、晃动或打盹。
4. 点击摸头、求一句开工签，短暂回应后安静。开工签使用本地预设文案，不调用模型。
5. 默认无声。安静模式减少自动气泡，减少动画模式使用静态或低动效。隐藏后可以通过菜单栏或快捷键找回。
6. 点击任务气泡唤回 DSH，并请求打开对应会话。仅导航，不代用户批准操作或发送消息。
7. DSH 宿主退出、插件停用或桥接不可达后，伴随程序退出，不保留孤立后台进程。
8. 拖动到屏幕左右边缘时，按宠物与悬停按钮的实际范围限制位置，透明留白不占拖动边界；设置和气泡向屏幕内展开。
9. 悬停工具栏提供「返回刚才的 DSH 聊天」，回到上次选中的会话，与任务优先级提示分别处理。

## 状态的含义

| 状态 | 含义 | 表现 |
| --- | --- | --- |
| offline | 没有有效 DSH 状态来源，或连接过期 | 明确显示未连接，不伪造任务 |
| idle | 已连接，当前没有需要展示的任务活动 | 喝茶、晃腿 |
| running | DSH 明确标记会话正在运行 | 算盘、电脑 |
| waiting | DSH 有待处理的审批或问题 | 举“掌柜请过目” |
| ready | DSH 标记已完成且有未读活动 | 元宝作揖一次 |
| blocked | DSH 投影明确包含错误 | 挠头、工具箱 |
| sleeping | 本地长时间空闲的表现状态 | 趴云睡觉 |
| pet | 用户主动点击的短暂表现状态 | 眯眼、爱心 |

多个会话同时有活动时优先展示 waiting > blocked > ready > running > idle。点击“任务结束”只表示一轮工作结束，不宣称测试通过或需求正确。没有错误证据时不能推测 blocked。

## 首版边界

养成、换装、番茄钟、签到、商城、饥饿值和独立聊天暂缓。功德联动保留为后续功能，首版不新建一套功德货币，不读取或修改主题的计数。

浏览器预览是独立演示环境，清楚标注演示状态，不能作为 DSH 联动或桌面悬浮验收的替代。完全退出 DSH 后继续养宠不在首版范围内。
