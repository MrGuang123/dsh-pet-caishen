# 阿财产品共识

状态：2026-10-19 确认首版基线；2026-10-22 确认当前阶段整理并实施 2D 体验增强，3D 排至再下一阶段。开发与验收以本文为准。

本文区分首版基线与后续目标。0.2.0-rc.1 已实现新增目标的功能代码，作为预发布候选交付；实现状态与实机缺口以验证记录为准，不代表整体阶段已验收；实际验证结果见 [验证记录](VALIDATION.md)。详细需求见 [当前阶段需求](REQUIREMENTS.md)，执行顺序见 [实施计划](IMPLEMENTATION_PLAN.md)。当前正在按实施计划开发 2D 增强，3D 仍后置。

## 角色

中文名：阿财；拼音／技术标识：`acai`；英文显示名：**Acai**。

阿财是一位陪伴开发工作的 Q 版小财神。圆脸、短胡子、红衣描金、祥云，与 `theme-caishen` 的暖纸／深檀配色相配；墨镜、咖啡、算盘、元宝是动作道具。性格亲切、幽默，有一点财迷和偷懒，不催促用户加班。

主题继续负责界面外观，阿财负责跨应用陪伴与任务反馈。宠物可独立使用，不要求安装财神主题，不修改主题文件或用户的提示词库。

## 首版核心体验

1. 阿财使用独立透明置顶桌面窗口；切换应用、最小化 DSH 后仍可见。优先 macOS，Windows／Linux 后续单独适配。
2. 可拖动、记住位置、调整大小、收起／唤回；透明空白区域穿透鼠标，不抢正在使用应用的焦点。
3. DSH 运行任务时拨算盘；需要用户决定时举牌；任务结束时抱元宝庆祝；遇到明确错误时挠头；空闲会呼吸、晃动或打盹。
4. 点击摸头、求一句开工签，短暂回应后安静。开工签使用本地预设文案，不调用模型。
5. 默认无声。安静模式减少自动气泡，减少动画模式使用静态或低动效。隐藏后可以通过菜单栏或快捷键找回。
6. 点击任务气泡唤回 DSH，并请求打开对应会话。仅导航，不代用户批准操作或发送消息。
7. DSH 宿主退出、插件停用或桥接不可达后，伴随程序退出，不保留孤立后台进程。
8. 拖动到屏幕左右边缘时，按宠物与悬停按钮的实际范围限制位置，透明留白不占拖动边界；设置和气泡向屏幕内展开。
9. 悬停工具栏提供「返回刚才的 DSH 聊天」，回到上次选中的会话，与任务优先级提示分别处理。

## 状态的含义

| 状态 | 含义 | 表现 |
| --- | --- | --- |
| offline | 没有有效 DSH 状态来源，或连接过期 | 明确显示未连接，不伪造任务 |
| idle | 已连接，当前没有需要展示的任务活动 | 喝茶、晃腿 |
| running | DSH 明确标记会话正在运行 | 算盘、电脑 |
| waiting | DSH 有待处理的审批或问题 | 举“掌柜请过目” |
| ready | DSH 标记已完成且有未读活动 | 元宝作揖一次 |
| blocked | DSH 投影明确包含错误 | 挠头、工具箱 |
| sleeping | 本地长时间空闲的表现状态 | 趴云睡觉 |
| pet | 用户主动点击的短暂表现状态 | 眯眼、爱心 |

多个会话同时有活动时优先展示 waiting > blocked > ready > running > idle。点击“任务结束”只表示一轮工作结束，不宣称测试通过或需求正确。没有错误证据时不能推测 blocked。

## 首版边界

养成、换装、番茄钟、签到、商城、饥饿值和独立聊天暂缓。功德点击的金币视觉反馈已实现；功德计数联动仍暂缓，不新建一套功德货币，不读取或修改主题的计数。

浏览器预览是独立演示环境，清楚标注演示状态，不能作为 DSH 联动或桌面悬浮验收的替代。完全退出 DSH 后继续养宠不在首版范围内。

## 当前阶段：2D 任务反馈与陪伴体验增强

保留现有 SVG 角色和 macOS 伴随程序，以任务信息准确、提醒适度、角色自然及桌面可靠性为目标。目标 DSH 仍为 `0.2.1-rc.2`，macOS 最低仍为 13；不因需求规划扩大平台兼容声明。

| 方向 | 本阶段目标 | 需求 |
| --- | --- | --- |
| 任务准确性 | 气泡显示标题并固定导航目标；按本轮事实去重庆祝；提醒消除不改变真实结果；摸头保留重要业务状态 | R01–R03 |
| 多任务与提醒 | 当前任务数量和列表；提醒分级、暂静 30 分钟；迷你陪伴；真实等待类型、运行时长与停止反馈 | R04–R07 |
| 角色与界面 | 本地文案防重复、轻互动；眉眼嘴型、动作停顿；小尺寸、大字、点击范围、首次引导；统一低动效策略 | R08–R11 |
| 桌面与可靠性 | 锁定位置、停靠与重置位置、可配置快捷键；多实例归属；隐藏节能；渲染就绪与恢复；最小诊断 | R12–R15 |
| 验收 | 分层记录离线、隔离真实运行库、浏览器、原生及真实 DSH 安装结果，补齐现有实机缺口 | R16 |

本阶段统一遵守以下规则：

- 任务列表只包含当前来源能够投影的存活 root 活动，不承诺完整任务历史；只接收标题、状态、必要交互标志和生命周期元数据，不读取正文、工具参数或推理。
- 业务状态与本地动作分开。摸头、打盹、求签和动画不能清除待处理交互、错误或待查看标记，也不能遮掉重要的状态入口。
- 完成事实与提醒展示分开。只有真实 `completed` 可触发本轮结束；同一轮只庆祝一次。导航、收起提醒只影响对应提醒，不批准审批、不回答问题、不把错误变为成功；会话选中也不表示用户完整阅读。
- 所有自动提醒默认无声。保留用户主动查看入口；暂静不丢失事实，不积压到期后集中弹出。
- 新增偏好需兼容现有尺寸、安静模式、减少动画及显示偏好；任务标题、会话标识与事件信息不写入偏好或诊断文件。
- 协议扩展在实现时同步宿主、网页、原生、测试与 [协议文档](PROTOCOL.md)；当前协议文档仍描述已实现接口，需求文档不代表接口已上线。

## 再下一阶段：3D 阿财

3D 是已排定的后续优化方向，在本阶段验收完成后启动。当前阶段不引入 3D 引擎、模型、精灵序列或相关运行依赖；通过拆开任务状态与角色表现，为更换渲染方式保留接口。

后续先确认角色风格与动作（圆润手办风为候选），再对比预渲染透明动画和轻量实时 3D。保留现有桌面窗口、状态、导航和气泡；用同机原生 A/B 测量 CPU、GPU、内存、帧时间与能耗后选择路线，不预先承诺占用百分比。隐藏暂停、减少动态与 SVG 备用形象是评估条件。macOS 13、Intel 和 Apple Silicon 的支持结论分别记录。
