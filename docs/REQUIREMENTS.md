# 阿财 2D 体验增强需求

整理日期：2026-10-22。本文记录本轮讨论确认的当前阶段目标；产品范围以 [PRODUCT.md](PRODUCT.md) 为准，实现顺序见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。

本文是需求基线；2026-10-23 工作树已实现以下条目，均保留验收状态，具体证据与未完成专项见 [VALIDATION.md](VALIDATION.md) 和实施计划进度表。实现不等于发布或全部实机验收。目标保持 DSH `0.2.1-rc.2`、macOS 13 及以上；不扩大平台承诺。

## 已有基础与本轮增量

现有产品已有原生透明悬浮窗口、拖动和位置记忆、大小设置、收起／唤回、任务状态、返回聊天、摸头求签、金币反馈、安静及减少动画选项；角色沿用红衣描金、玉饰、短胡子和祥云。上述能力继续保留，本轮重点是语义修复、并发任务体验、提醒控制、表现力、可访问性与可靠性。

优先级：**P0** 为任务语义及发布门槛；**P1** 为主要体验与可靠性；**P2** 为当前阶段的后续增强。优先级不等于已实现；每项按验收证据关闭。

## 任务与提醒

### R01 · 气泡标题与会话绑定 · P0 · 已实现／待完整验收

- 气泡同时提供任务标题与明确状态；标题缺失使用通用名称，所有任务文字以 `textContent` 或 React 转义展示。
- 打开按钮绑定气泡生成时的会话，不能点击时改取最新的优先任务；异步更新和多任务切换不改变已展示入口的目标。
- 验收：A 气泡出现后 B 抢占优先级，点击仍进入 A；目标不再有效时提示无法打开，不静默跳转 B；特殊字符按文字显示。

### R02 · 单次完成庆祝与提醒消除 · P0 · 已实现／待完整验收

- 仅真实 `completed` 显示“本轮结束”；每次新的完成事件只庆祝一次，随后安静持元宝或显示待查看标记。事件身份须区分同一会话的不同轮次，不能以标题或 `updatedAt` 变化触发新庆祝。
- 通过宠物成功返回对应会话、可靠确认 DSH 已选中该会话，或用户主动收起该条提醒后，消除对应完成提醒；失败导航不消除，新一轮活动不被旧操作清除。
- 选中会话可消退对应提醒，不宣称用户完整阅读、任务正确或测试通过，也不批量清除其他会话提醒；明确错误与待处理交互事实不因导航或本地收起而清除。
- 验收：连续轮询、标题更新、并发完成、切换会话、导航失败和同会话的新完成事件分别检查；旧导航确认不能消除新一轮提醒，作揖和星光均有限次结束。

### R03 · 任务状态与摸头表现解耦 · P0 · 已实现／待完整验收

- 摸头、求签、金币和睡觉属于本地表现；不得替换宿主事实、任务标题、重要标记或返回入口。
- 摸头可以眯眼或短暂回应；遇到审批、问题和错误时，任务反馈仍清晰可见，互动结束后自然回到当前任务表现。
- 验收：waiting／blocked／ready 时连续摸头和拖动，状态及目标会话不变；拖动结束不误触摸头。

### R04 · 多任务面板 · P1 · 已实现／待完整验收

- 基于宿主当前追踪的存活 root 会话，显示待处理、运行等状态数量；展开后列出标题、状态和各自的返回入口，保持现有状态优先级。
- 列表与数量使用同一快照，单会话不重复计数；具体审批／问题类型只有可靠来源时才分开统计。
- 验收：并发、移除、断连和空列表均正确；长标题可识别、列表可操作；不把历史会话或子 Agent 列成新的根任务。此面板不承诺任务历史中心。

### R05 · 提醒分级与暂静 · P1 · 已实现／待完整验收

- 提供“全部提醒／仅需我处理／安静陪伴”；新增“安静 30 分钟”，到期恢复暂静前的选择，界面明确显示暂静状态与剩余时间。
- 保存暂静截止时刻与此前模式；重启后未到期则继续剩余暂静，已到期则恢复此前模式，不能因重启重新计算 30 分钟。
- “仅需我处理”允许审批、问题和明确错误的自动提示，完成只做轻量视觉反馈；“安静陪伴”及暂静期间抑制自动气泡，状态、待处理标记和主动查看入口仍保留。
- 兼容现有 `quiet` 偏好；旧值的迁移和两端协议须有明确映射，不能升级后意外恢复打扰。默认继续无声。
- 验收：各模式、暂静恢复、重新打开设置及已有偏好迁移；提醒策略只影响表现，不改变任务状态，不回答问题、不批准操作。

### R07 · 等待类型、运行时长与停止反馈 · P1 · 已实现／待完整验收

- 从可靠宿主字段区分“待确认操作／待回答问题”；没有依据时使用通用等待文字，不读取或投影审批参数及问题正文。
- 可靠取得运行开始时刻后才展示运行时长；未知时不编造数字或进度。明确停止／取消时显示对应事实，不复用“本轮结束”。
- 验收：已知与未知等待类型、缺失开始时刻、完成、取消、异常及断连分别覆盖；观察器透明调用 `next()` 并原样传递结果或错误。

## 陪伴、外观与易用性

### R06 · 迷你陪伴模式 · P1 · 已实现／待完整验收

- 新增可选择的紧凑模式，平时以角色为主，悬停或主动操作可展开状态与入口；重要待处理活动保留可识别标记，不能被完全折叠隐藏。
- 切换模式后同步实际交互区域、拖动范围及面板避边，保留现有收起／唤回入口。
- 验收：三档角色大小、重要状态、屏幕两侧、穿透和模式切换；透明留白不扩大桌面点击占用。

### R08 · 本地文案与轻互动 · P2 · 已实现／待完整验收

- 扩充开工签和短回应，短时间内避免重复；保持本地预设、无需模型调用、不催促加班。
- 在喝茶、整理帽子、伸懒腰等少量动作中选择符合当前状态的轻互动；任务重要提示优先，频率可控。
- 验收：重复点击、候选耗尽、安静模式和减少动画模式；不新增货币、签到、养成数值或主题计数写入。

### R09 · 表情与动作节奏 · P1 · 已实现／待完整验收

- 保留现有角色辨识度，用眉眼、嘴型和视线辅助区分运行、等待、完成及明确错误；不能只依赖道具或颜色。
- 减少头、手、胡子与漂浮的持续叠加，加入停顿；运行优先表现工作动作，空闲动作间歇出现，完成遵守 R02 的单次规则。
- 验收：各业务状态静态可辨，连续切换不卡在旧表情；长时间观察无持续密集摆动，减少动画下仍能读懂状态。

### R10 · 小尺寸、对比与操作可访问性 · P1 · 已实现／待完整验收

- 在 120／160／240px 分别调整细节层级；小尺寸保留帽翅、圆脸、短胡子和祥云轮廓，避免细纹与道具挤作一团。
- 提供大字选项；主要操作的实际点击区至少 32×32 CSS px，带清晰名称及键盘焦点；扩大点击区时同步穿透区域。
- 首次使用提供一次可关闭、可重新查看的简短引导，说明拖动、任务入口、设置与收起后唤回方式。
- 验收：浅色、深色及复杂壁纸，长中文标题、大字、键盘操作和屏幕边缘；重要文字不被裁切，气泡不遮住主要入口。

### R11 · 减少动态一致性 · P1 · 已实现／待完整验收

- 系统“减少动态”和手动开关共同决定最终低动效表现：任一开启即生效；关闭手动开关不能覆盖系统偏好。
- 覆盖角色、金币、爱心、星光、气泡及后续新增动作；以静态状态或短淡入反馈保留信息。
- 验收：启动时、运行中切换系统偏好和手动偏好的全部组合；已开始的循环和金币动画也应及时停止或降级。

### R12 · 位置与快捷键管理 · P2 · 已实现／待完整验收

- 提供锁定位置、可选择的靠边停靠，以及“移回当前屏幕”；锁定后阻止拖动，设置与唤回仍可使用。
- 允许修改／恢复唤回快捷键；注册失败或冲突在界面给出明确状态及可用的菜单栏入口，不能只写日志。
- 先核对多 profile 的实际窗口归属与现有位置存储行为，再隔离各 profile 的位置与显示偏好；唤回及返回目标不能串到其他 profile，不擅改日常 profile。
- 验收：锁定／解锁、负坐标副屏、屏幕移除及缩放变化、左右停靠、快捷键冲突、重启恢复及隔离 profile 并行运行；不修改系统或其他应用的快捷键。

## 可靠性、性能与交付

### R13 · 隐藏节能与移动去重 · P1 · 已短采样／已实现／待完整验收

- 先记录当前版本在空闲、任务运行、拖动、隐藏四种场景的 CPU、内存、能耗及关键唤醒／刷新频率，再决定调整策略；不预先承诺节省比例。
- 隐藏时暂停无用动画与布局刷新；静止时避免持续高频指针检测和重复位置写入，拖动时保持现有固定鼠标锚点与可靠松手检测。
- 验收：同机同场景前后对比；收起／唤回、任务状态更新、连接过期判断和宿主退出清理均不退化。节能不能使 waiting 或离线状态永久滞后。

### R14 · 渲染就绪与失败恢复 · P1 · 已实现／待完整验收

- 区分原生进程握手、窗口可见和角色可交互就绪；只有收到可信页面就绪确认才报告渲染可用。
- 对页面加载失败、WebView 内容进程终止和角色资源失败提供有界重试与明确失败状态；页面可用但角色动画失败时提供静态 SVG 备用显示。
- 验收：缺失就绪、加载错误、内容进程终止、恢复成功及持续失败；不得无限重载或显示假成功，菜单栏的收起、重试与退出入口仍可用。

### R15 · 最小诊断信息 · P2 · 已实现／待完整验收

- 提供预览后主动复制诊断信息，仅含插件／DSH／原生版本、协议版本、系统版本与架构、连接／可见／就绪状态和枚举故障类型。
- 不含标题、会话 ID、消息正文、工具参数、推理、凭证、完整 URL、端口、用户路径或偏好文件内容；错误采用固定分类，不直接透传原始异常。
- 验收：正常、未连接、加载失败等场景，逐项检查复制内容与故障路径日志；不自动上传诊断或向他人发送。

### R16 · 原生与真实 DSH 验收 · P0 · 待验收

- 将离线测试、隔离真实运行库、浏览器预览、原生窗口、日常 DSH 完整安装分别记录；测试通过不替代实机交互验收。
- 覆盖真实运行／审批／问题／完成／取消／错误、并发与对应会话返回、提醒模式、连续拖动、多屏、全屏 Space、穿透、系统减少动态、快捷键、隐藏及退出清理。
- 有行为变更运行相关测试及 `npm run check`、`npm test`；macOS 构建后运行 `npm run check:package`；预编译分发执行 `npm run prepare:native` 和 `npm run check:native`。
- 验收记录注明机器架构、版本、场景与证据；Intel 未实测不得宣称通过。不得修改已安装 DSH App、日常 profile 或同级主题。

## 后续阶段与暂缓项

3D 已排至当前 2D 增强阶段之后，先做独立视觉及性能原型评估；本轮不替换渲染器，不对 3D 帧率、内存或续航作承诺。

养成、换装／节日配饰、番茄钟、签到、商城、饥饿值、独立聊天、脱离 DSH 常驻养宠、功德计数联动及 Windows／Linux 适配仍为后续候选，不因本次讨论转为当前交付承诺。
